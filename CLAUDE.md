# Project Instructions

## Documentation

Keep README and `docs/` edits **concise and precise**. Match the surrounding
terse voice: state the rule and its consequence, then stop. No restating a point
in a second form, no examples the reader can infer, no clauses that only justify
the design.

Every change to README.md must be mirrored in README.zh-CN.md (same for the
`docs/*.zh-CN.md` pairs), at the same length.
